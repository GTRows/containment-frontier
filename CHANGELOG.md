# 0.5.0-beta.1 - GitHub prerelease

Based on the immutable private59 a9 campaign build. Distributed through the GitHub prerelease. CurseForge catalog approval remains pending.

- Adds the authored technology campaign with 14 chapters and 638 quests, regional commissioning, physical logistics bridges and faction services.
- Integrates Normal/Expert recipe paths, one-time campaign difficulty selection, staged extraction and engineered defense.
- Includes four shared research branches and medicinal genetics feeding the treatment production chain.
- Provides personal Field Tablets, scoped machine screens, TR/EN owned text, English item names, JEI shortcuts and finite personal clone lives.
- Includes automatic world backups. A Docker server package exists in development; public binary distribution review remains pending.
- Carries the private59 fixes for fresh-client options data version, authored-world experimental confirmation, crop-tool priority and HammerLib creative-tab publication.

## Validation scope

196 Java test programs and 626 Python tests across 64 isolated modules pass on the recorded source. The a9 module, native backup/restore, FTB reward backend, owned-model/JEI and bounded client UI checks have exact recorded artifact scopes. Earlier defense/research/genetics fixtures retain their original module scopes.

Full earned solo/coop progression, naturally obtained high-trait medicinal crops, sustained treatment manufacturing and long-session performance remain open beta acceptance work. Do not treat fixture results as a completed survival playthrough. Back up before changing versions; a fresh campaign is recommended.
