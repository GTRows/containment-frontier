# Installation

1. Install the official CurseForge App and Java 21.
2. Download `Containment-Frontier-0.5.0-beta.2-CurseForge.zip` and `SHA256SUMS.txt` from the [GitHub beta release](https://github.com/GTRows/containment-frontier/releases/tag/v0.5.0-beta.2).
3. Compare the downloaded ZIP's SHA256 to the published checksums. Import the ZIP through CurseForge App > Minecraft > Create/Import profile. Keep a separate new profile for this beta.
4. The App retrieves the pinned third-party mods and visuals from their official project references. The original **Continuity Frontier** campaign JAR is included as an override. The App may identify it as unhosted until its separate CurseForge project approval is complete; verify the download source and checksum before installing it. No approved CurseForge catalog listing is claimed.
5. Use Minecraft **1.21.1**, NeoForge **21.1.265**, Java **21** and a **6144 MB** Java heap as the reference tested configuration. Hardware and shader requirements vary; 6 GB is not a guaranteed minimum for every computer.
6. Open the included `continuity_frontier_v1` world or create a fresh **Survival** world with the campaign preset. Keep Minecraft's own **Hardcore** toggle off: this campaign implements finite personal clones itself.
7. Choose Normal/Expert and campaign difficulty once. Use the **Field Tablet** to register an FTB Teams party and follow the opening quests. Solo parties are supported.

Each registered participant needs a ready personal clone. If any participant dies without one, the shared campaign fails for everyone, even if other participants have spare clones. Recovery requires an explicit operator restore or a new campaign.

Automatic backups use Simple Backups. Keep independent off-machine copies and the matching pack version. Never overwrite an existing campaign with an experimental update.

The client ZIP does not contain a standalone dedicated-server installation. The matching Docker server's public distribution review is pending.

In Operations, open **Language** to reach **Settings**. English, Russian, Spanish, Brazilian Portuguese, German and Turkish apply only to the pack-owned interface, quests, story and notices. Your preference is saved per client profile. Minecraft's global language and item/block names are unaffected.
